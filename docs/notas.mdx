# Notas e média ponderada

Notas por disciplina e média ponderada por créditos, geral e por série, calculadas
automaticamente.

<GradesCalculator />

:::note[Como lançar uma nota]
Edite `src/data/notas.json`. A chave é o **código** da disciplina; o valor, a nota (ou `null` se
ainda não saiu):

```json
"EX301": 8.5
```

A regra de aprovação (escala, nota mínima, recuperação) fica no bloco `config` do mesmo arquivo.
`npm run validate` recusa nota fora da escala e código que não exista na matriz.
:::
