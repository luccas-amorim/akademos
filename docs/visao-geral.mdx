# Akademos

Gestão acadêmica aberta: grade curricular, horário, notas, integralização e progresso do curso,
num site derivado de três arquivos de dados que o próprio estudante controla.

:::info[Dados de exemplo]
Tudo o que aparece neste site é **fictício**: o <strong>{curriculo.meta.curso}</strong> da{' '}
<strong>{curriculo.meta.instituicao}</strong>, com {curriculo.meta.series} séries e{' '}
{curriculo.disciplinas.length} disciplinas inventadas. Para usar com o seu curso, edite os arquivos
em `src/data/` — o passo a passo está no
[README](https://github.com/luccas-amorim/akademos#como-usar).
:::

---

## O que cada página mostra

| Página | O que traz |
|---|---|
| [Progresso](/progresso) | Créditos e carga horária cumpridos, carga por semestre e distribuição por área |
| [Matriz curricular](/matriz) | Todas as disciplinas, série a série, com a situação de cada uma |
| [Horário](/horario) | A semana do semestre atual, com os dias livres |
| [Notas](/notas) | Média ponderada por créditos, geral e por série |
| [Integralização](/integralizacao) | O que cursar em cada semestre até a formatura, em uma ou mais rotas |

---

## De onde vêm os números

| Arquivo | O que guarda |
|---|---|
| `src/data/curriculo.json` | a matriz, as regras do curso (`config`), o calendário e as rotas até a formatura |
| `src/data/horario.json` | as aulas de cada semestre, por dia e faixa de horário |
| `src/data/notas.json` | as notas lançadas e a regra de aprovação |

Nenhum número é digitado nas páginas: se um dado muda, todas as páginas mudam juntas.
`npm run validate` confere que os três arquivos concordam entre si antes de publicar.
