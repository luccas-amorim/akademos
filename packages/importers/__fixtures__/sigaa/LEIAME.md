# Fixtures do SIGAA

HTML **sintético** que reproduz a estrutura das páginas do SIGAA usadas pelo conector
(formulários JSF com `javax.faces.ViewState`, menu do portal do discente, consulta pública de
turmas). Não foi capturado de nenhuma instituição real e não contém dados de pessoas.

Quando o HTML real de uma instituição mudar, grave a página nova aqui (anonimizada), ajuste o
conector e suba a `versao` dele em `src/conectores/sigaa/sigaa.ts`.
